# 047 结果：场地页改成日本足迹地图

场地页以都道府县足迹图为主。圆点按场次放大，点圆点或右侧名单可以下到会场，再下到单场公演。

## 粒度

872 场、215 个会场。东京 605 场 / 102 个会场，关东以外每个县大多只有几场。按会场打点会在东京都心叠成一团，库里也没有会场经纬度。这一版按都道府县打点：有演出的 23 个县各一个锚点。

锚点是县厅所在城市的城市中心，不是会场地址。2026-10-27 用英文维基的 MediaWiki `prop=coordinates` 读主坐标，四舍五入到 5 位小数，写在 `region_geo.lat/lng`。对应页面记在 `region_geo.source_url`（例如东京是 https://en.wikipedia.org/wiki/Tokyo ，神奈川是横滨页）。这些 URL 不进 `sources` 表：那张表的检查要求页面提到 iLiFE!，而这批坐标只是地图锚点。页面脚注写明圆点不是具体会场。

## 图

陆地轮廓来自 Natural Earth 1:50m admin-0 的日本（公有领域），路径内联在 `app.js`，没有新图片、也没有进 R2。冲绳单独缩在左下角，避免为了放进行政范围把本州压扁。没有演出的远岛（小笠原等）不画进主图。

关东几个县的锚点相距只有十几到几十像素，东京的圆点又最大。靠东、并且和邻县挤在一起的县，名称和场次排在地图右侧，用细线连回圆点。大阪、爱知等大点写在圆点旁边，并避开别的圆点。场次少于 4、又不和别人挤开的县只留圆点，名称在右侧名单里。

## 页面

- 桌面：地图在左，名单贴在右侧，可以滚动。
- 手机：地图在上（大约半屏），名单在下。点地图上的县会把名单滚进视口。
- 点县 → 该县会场（按场次）。点会场 → 公演，链到 `lives.html?l=<id>`。
- 原来的 `venues.html?v=` 仍然打开该会场。`?p=` 打开一个县。点海面回到全部。
- 会场行可以搜地区或会场名。线上和未确认不给 Google 地图链接；有地名的会场给搜索链接，不编造坐标。

配色沿用站点的米色底和 `#e4007f`。没有用 MIRUGUMI 的字标或顶栏ticker。
