# 050 抽签时空高熵随机数算法与日本神签 1000+ 专属题库扩容

## 目标

1. **解决用户反馈的「签和签语为什么总是一样」的核心痛点**：
   - 诊断并说明原版本中主签语（Tagline）与吉级别 1:1 死绑定、一言签语（Motto）仅有 12 条的根本原因；
   - 详尽回答用户「现在签语有多少」的疑问。
2. **结合时间与交互物理位置的多重熵源混合随机算法（Spatio-Temporal Entropy RNG）**：
   - 采集点击/触控物理交互位置：`clientX`、`clientY`、`screenX`、`screenY`、偏移量 `offsetX`、`offsetY`；
   - 采集高精度微秒级时间戳：`performance.now()`（纳秒浮点） + `Date.now()`（毫秒时间戳） + 时区偏移与交互计数；
   - 结合视口几何参数（视口宽高、滚动距离）与 Web Crypto 硬件真随机；
   - 通过 4 轮雪崩置乱哈希驱动 Xoshiro128+ PRNG，确保每一次时间差异与像素级位置差异均能引发彻底不同的随机序列。
3. **日本经典神社神签与现代推活（推し活）吉网站调研**：
   - 调研浅草寺·元三大师百籤（1~100番编号原型）、明治神宫大御心（和歌心灵指引）、Hoyme（推活专精占卜）、おみくじ堂（温柔治愈）、ShindanMaker 等体系；
   - 提炼 9 大核心偶像应援维度：现场·神席、视线·回应、欢呼·热唱、特典·拍立得、担当色·手灯、神曲·旋律、同担·羁绊、日常·元气、未来·心愿。
4. **建设 1,000+ 首编号专属神签题库（第 1 番 ～ 第 1000 番）**：
   - **全量 1,000 条** 独一无二神签，支持粉丝每天抽一次连续近 3 年绝不重复；
   - 纯正神社正向吉配比：大吉 250 条（25%）、中吉 250 条（25%）、小吉 200 条（20%）、吉 200 条（20%）、末吉 100 条（10%）；
   - 每支签均包含：签号（第◯番 / No.◯）、签题（Tagline）、签文导引（Sub）、每日箴言（Motto），全部配备地道中日英三语（zh / ja / en）对照；
   - 幸运物品（`LUCK_ITEMS`）与今日行动（`LUCK_ACTS`）各扩充至 40 款，配合 12 款幸运推色，整体组合空间超数亿种。
5. **轻量高性能与向下兼容**：
   - 采用纯内存生成算法，gzip 压缩仅增加约 25KB，加载耗时小于 0.1ms，零网络延迟；
   - 卡片界面、复制分享文案与 9:16 分享图完整标注签号与三语切换；
   - 历史手帐与本地存储完美向下兼容旧版。
