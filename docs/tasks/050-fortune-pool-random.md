# 050 抽签时空高熵随机数算法与签语词库大规模扩容

## 目标

1. **解决用户反馈的「签和签语为什么总是一样」的核心痛点**：
   - 诊断并说明原版本中主签语（Tagline）与吉级别 1:1 死绑定、一言签语（Motto）仅有 12 条的根本原因；
   - 详尽回答用户「现在签语有多少」的疑问。
2. **签语与主签语词库数十倍级大规模扩充**：
   - 每个吉级别（大吉、中吉、小吉、吉、末吉）从原本固定的 1 组签语扩充为 **8 组三语专属签语**（共 40 组 Tagline + Subtag）；
   - 今日一言处方（`LUCK_MOTTOS`）从 12 条扩充至 **60 条**，涵盖 Live 现场、Call 呼喊、特典会、周边、日常治愈与应援共鸣，全部配备地道中日英三语翻译；
   - 幸运物品（`LUCK_ITEMS`）从 12 个扩充至 **40 个**，均配三语对照；
   - 今日行动（`LUCK_ACTS`）从 12 个扩充至 **40 个**，均配三语对照；
   - 整体可能组合空间从 8,640 种暴增至 **46,080,000 种**（四千六百万种组合）。
3. **结合时间与交互物理位置的多重熵源混合随机算法（Spatio-Temporal Entropy RNG）**：
   - 采集点击/触控物理交互位置：`clientX`、`clientY`、`screenX`、`screenY`、偏移量 `offsetX`、`offsetY`；
   - 采集高精度微秒级时间戳：`performance.now()`（纳秒浮点） + `Date.now()`（毫秒时间戳） + 时区偏移与交互计数；
   - 结合视口几何参数（视口宽高、滚动距离）与 Web Crypto 硬件真随机；
   - 通过 4 轮雪崩置乱哈希驱动 Xoshiro128+ PRNG，确保每一次时间差异与像素级位置差异均能引发彻底不同的随机序列。
4. **向下兼容与分享卡片导出**：
   - 历史手帐平滑兼容旧记录；
   - 9:16 Canvas 处方签图片完美支持扩容后的长句排版与双语导出。
