# 052 成员页应援色橱窗

## 目标

成员列表页保持原来的时间轴和成员卡片。打开一位成员（`?m=`）时，赛马娘式橱窗只出现在这张成员卡片里面：应援色、大图、卡片内头像条和左右切换、形象条、过渡。不要把整页收成顶部一条常驻成员条。

## 范围

- `app.js` 成员页：列表仍是时间轴 / 成员卡片。详情卡片内部才有头像条、应援色橱窗、左右切换和形象条。
- `style.css` 应援色只染打开的那张卡片，顶栏和列表页不上色。
- 不改 `db/ilife.sqlite`，不手改 `data/*.json` 的事实，不上传新图。

## 数据来源

不新增事实。照片用已有 `latestPhoto` 与各时期个人图；应援色用 `members.json` 的 `hex`；口号、读音等用原字段。形象条只在同一成员至少有两张非插画个人图时出现，标签用时期名或拍摄日期，不编造衣装名。

## 验收标准

- [ ] 未选成员时，页面仍是原来的时间轴 / 成员卡片，顶部没有常驻头像条，页面底色不上应援色。
- [ ] 打开 `?m=` 后，橱窗在成员卡片内部：卡片内可滑动头像（现役，可展开前成员）、大图、日文名、假名、口号（若有）、应援色、左右箭头。深链仍可用。
- [ ] 换人时主图交叉淡入、橱窗底色跟着应援色过渡。系统开启「减少动态效果」时不做过渡。
- [ ] 至少两位现役成员的应援色明显不同（例如赤与绿）。顶栏不变成成员色。
- [ ] 有两张以上个人图时，主图下有形象切换条，点缩略图只换主图。只有一张图时不出现该条。
- [ ] 桌面和手机宽度无整页横向滚动，图片不裁切。
- [ ] 新文案走 `i18n('中文原文')`。`python3 db/export.py --check` 通过。
