# 052 成员页应援色橱窗

## 目标

成员页切换时要像赛马娘角色页那样：点一位成员就整页换成她的应援色，大图、口号、资料一起换，并且有过渡。成员列表放在页面最上面，点头像就能换人，不必先回到时间轴。

## 范围

- `app.js` 成员页（`members.html` / `?m=`）：顶部横向成员条、角色橱窗、左右切换、形象条、中日英文案。
- `style.css` 只给成员页内容上色，顶栏导航仍用站点粉色。
- 不改 `db/ilife.sqlite`，不手改 `data/*.json` 的事实，不上传新图。时间轴和成员卡片保留，放在成员条下面。

## 数据来源

不新增事实。照片用已有 `latestPhoto` 与各时期个人图；应援色用 `members.json` 的 `hex`；口号、读音等用原字段。形象条只在同一成员至少有两张非插画个人图时出现，标签用时期名或拍摄日期，不编造衣装名。

## 验收标准

- [ ] 成员页最上方是可横向滑动的成员头像条。默认现役；可切换「前成员」看到其余成员。当前成员用其应援色标出。
- [ ] 点头像或左右箭头进入橱窗：大图、日文名、假名、口号（若有）、应援色、原有资料字段。深链 `?m=` 仍可用。
- [ ] 换人时主图交叉淡入、橱窗底色跟着应援色过渡。系统开启「减少动态效果」时不做过渡。
- [ ] 至少两位现役成员的应援色明显不同（例如赤与绿）。顶栏不变成成员色。
- [ ] 有两张以上个人图时，主图下有形象切换条，点缩略图只换主图。只有一张图时不出现该条。
- [ ] 桌面和手机宽度无整页横向滚动，图片不裁切。
- [ ] 新文案走 `i18n('中文原文')`。`python3 db/export.py --check` 通过。
