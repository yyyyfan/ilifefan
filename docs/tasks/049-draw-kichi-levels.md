# 049 抽签增加吉的级别、卡哇伊吉祥物交互与每日限定求签

## 目标

1. 为抽签页（`draw.html`）与 900×1600 分享卡片增加御神签式的吉凶级别（全吉等级：大吉、中吉、小吉、吉、末吉），拍立得盖印与运势栏、分享图同步展示。
2. 抽推优先：默认进入「抽推」模式，选项卡顺序排在最前（`[🐰 抽推, 🎵 抽歌]`），文案与求签主旨默认指向推。
3. 表头瘦身与吉祥物入口：将抽签从全局顶部导航条移除，查考 iLiFE! 官方吉祥物白兔「アイラビット」（i-Rabbit），制成常驻右下角、可随心拖动、平滑吸边的萌物浮动入口；点击释放心跳与星光粒子爆开动画，引导求签。
4. 交互与视觉卡哇伊化：重构抽签页整体质感，告别生硬死板——草莓奶糖柔光渐变、和纸胶带质感、兔耳待机票签、糖果 3D 流光主按钮、双环御神签印章、棉花糖风格运势卡片。
5. 每日限定求签：每天推与歌各只能抽取 1 次（日本时间 JST 零点刷新）。选项卡清晰标注「已签 / 待抽」；当天已抽取后自动固定展示当天结果，提供快捷按钮切换抽取另一项，不可重复求签；两者皆抽完显示温馨提示。

## 范围

- **吉凶级别**：五级全吉池（大吉、中吉、小吉、吉、末吉，全吉无凶）。
- **拍立得印章**：`.dseal` 主显吉级别文字，当天首抽时带「今日首抽」，抽推时印章颜色与光环联动成员代表色。
- **今日运势**：包含签语、运势、幸运色、幸运物品、今日行动；900×1600 分享卡片绘制和纸胶带、双环吉印章与运势行。
- **默认模式与选项卡**：默认开启抽推，标签栏为 `[🐰 抽推, 🎵 抽歌]`。
- **每日限次 1 次**：当天推与歌各限抽 1 次；已抽后展示 `✨ 今日限定已出`，去除重复抽取按钮，并提供「去抽今日之歌 / 推 ↗」平滑切换；历史记录点击可回看，回看带有「返回今日」按钮。
- **导航与吉祥物小组件**：从 `NAV` 移除 DRAW；全站注入 `#dmascot` 吉祥物（アイラビット头像截取已收录在 R2 的官方原图，免加冗余素材）；支持 pointer 拖拽、边界约束与松手靠边吸附；点击触发粉红爱心星光粒子（`dmascot-sparkle`）；抽签页点击引导滚动至抽签按钮或今日结果并触发果冻跳动。
- **卡哇伊 UI 改造**：3D 糖果凹凸按钮、扫光高光、和纸胶带、兔耳票签、软萌阴影。
- 不改动 SQLite 数据库，数据脚本 `python3 db/export.py --check` 严格通过。
