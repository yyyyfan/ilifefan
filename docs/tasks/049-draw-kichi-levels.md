# 049 抽签增加吉级别、卡哇伊吉祥物、每日限定求签与参考 Penpen 诊疗所交互重构

## 目标

1. **参考 Penpen 诊疗所（`https://penpen-clinic.app.workbuddy.host/`）交互与排列方式**，对 iLiFE! 抽签页进行全方位的视觉结构、交互层次与设计质感重构。
2. **全吉五级运势体系**：大吉、中吉、小吉、吉、末吉，全吉无凶，搭配双语签语口号（tagline）、处方消息（motto）、幸运色（带色块实心圆点）、幸运物品与今日行动。
3. **推在前面**：默认进入「抽推」模式，选项卡排在最前（`[🐰 抽推, 🎵 抽歌]`），文案与求签主旨默认指向推。
4. **官方吉祥物「アイラビット」双重交互**：
   - 顶部英雄区正中常驻轻柔浮动（bobbing）的吉祥物白兔徽章，点击迸发卡哇伊音效/粒子与祝福气泡；
   - 全站右下角常驻可自由拖拽、平滑吸边、带星光喷涌动画的萌物浮动入口。
5. **Penpen 风格大按钮 CTA**：
   - 未抽时呈现立体 3D 拟物底边、光泽斜掠扫光（shine）与悬浮轻微放大，文字动态显示「🌸 今日の推しを引く ♡」或「🎵 今日の曲を引く ♡」；
   - 当日已抽取后自动变为温润薄荷粉渐变状态「✨ 本日の処方は受け取り済み ♡」（`.cta.is-done`），点击平滑下滚查看今日处方，防止重复误抽。
6. **Penpen 风格摇签舞台（Draw Stage）**：
   - 抽取过程呈现粉嫩玻璃神签筒与竹签晃动动画（`.shake-wrap.is-shaking`）；
   - 带有三个可爱跳跳小圆点「おみくじを振っています...」与「アイラビット正在摇晃签筒，请稍等一下 ♡」。
7. **处方笺结果卡片（Prescription Card）**：
   - 顶部日期格式采用日式带星期格式：`2026.10.28（水）`；
   - 卡片带有和纸浅色横条网纹质感（`repeating-linear-gradient`）；
   - 顶部左右双栏：左侧虚线双环御神签吉级别 SVG 矢量印章（带今日限定标识），右侧主签语 tagline、日文副签语及彩底胶囊 badge；
   - 中间呈现微倾斜拍立得照片卡片（`.polaroid`）；
   - 处方项目行（`.rx-list`）：签语便签（`.rx-item.is-phrase`）、幸运颜色（带三层发光圆点）、幸运物品、今日行动；
   - 分享引导条（`.share-cta`）：「💌 今日のお守り、シェアしない？」「保存处方签 📸」；
   - 结果操作区：切换去抽另一项按钮（「去抽今日之歌 🎵 ↗」或「查看今日之歌 🎵 ↗」）、查看成员/歌曲档案链接。
8. **三栏特性卡片与图鉴式历史记录**：
   - 三栏圆角特性卡（每日一次求签、命中之推与音乐、保存分享处方签）；
   - 历史记录（`.dhist`）采用 Penpen 图鉴卡片网格排布，标有吉级别彩色胶囊徽章。
9. **每日限定求签**：每天推与歌各只能抽取 1 次（日本时间 JST 零点刷新）。选项卡清晰标注「已签 / 待抽」；不可重复求签。
10. **引入 Zen Maru Gothic 字体**：全站抽签区域统一呈现圆润、温暖的日系可爱感。
