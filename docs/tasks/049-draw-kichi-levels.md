# 049 抽签增加吉的级别

## 目标

为抽签页（`draw.html`）与 900×1600 分享卡片增加御神签式的吉凶级别（全吉等级：大吉、中吉、小吉、吉、末吉）。结果签纸拍立得上的圆章印章盖上对应的吉级别（当天首抽时带「今日首抽」），今日运势栏与分享卡片同步展示运势级别，让每次抽签与分享更具趣味与应援仪式感。

## 范围

- 运势级别设为五级全吉：大吉、中吉、小吉、吉、末吉（全为吉，不设凶）。
- 拍立得圆章（`.dseal`）改为主显吉级别文字；若为当天首抽则上方标「今日首抽」，并保留印章双环印记视觉。
- 签纸「今日运势」区域增加「运势：大吉」一行，且签语标为「签语 · 大吉」。
- 900×1600 分享卡片：圆章盖印与运势栏同步呈现吉级别与对应颜色。
- 历史记录卡片（`.dhi`）：小字展示吉级别（如「大吉 · 首抽」「中吉」等）。
- `localStorage`（`ilifefan-draw-v1`）兼容已有历史记录，旧记录缺省时平滑回退为「吉」。
- 不改动 SQLite 数据库，不增加网络依赖。

## 数据来源

词库与概率分布定义在 `app.js`。

## 验收标准

- [x] 抽签结果签纸拍立得上方的圆章印章醒目展示吉级别（大吉 / 中吉 / 小吉 / 吉 / 末吉）。
- [x] 当天模式第一次抽取时，圆章印章带「今日首抽」标识。
- [x] 签纸下方「今日运势」包含「运势」行并标注吉级别，签语小标题带有「签语 · <级别>」。
- [x] 抽推模式下，运势字样与印章颜色联动成员代表色。
- [x] 「保存卡片」生成的 900×1600 分享图上的圆章与运势栏完整展示吉级别。
- [x] 历史记录卡片中显示抽签结果的吉级别。
- [x] 旧记录或缺少级别字段时能平滑兼容，不报错。
- [x] `python3 db/export.py --check` 通过。
