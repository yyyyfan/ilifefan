本次迭代根据用户提供的参考站点（`https://penpen-clinic.app.workbuddy.host/` ぺんぺんの幸せ診療所 ♡），对 iLiFE! 抽签页进行了端到端的交互排列、视觉结构、运势逻辑与动画重构，全面实现了现代偶像应援网站的高质感萌系体验。

## 变更内容

1. **整体设计语言与排版（Zen Maru Gothic & Soft Pastel）**：
   - 引入 Google Fonts `Zen Maru Gothic` 圆体字体，让日文汉字、假名及数字呈现温润通透的圆角萌系质感。
   - 浅粉奶白渐变背景搭配和纸胶带与横纹信纸微肌理。
2. **Hero 区域重构（参考 Penpen 布局）**：
   - **眉毛标签**：`✿ 非公式ファンサイト ・ ファンメイド` 胶囊框。
   - **双语大标题**：日文渐变艺术字「今日の推しを、処方します。」/ 中文副标题「为你开一份，今天的好运处方 💕」（歌曲模式对应切换）。
   - **推在前面**：默认进入抽推模式，选项卡排列为 `[🐰 抽推, 🎵 抽歌]`，带有实时「待抽 / 已签」状态标签。
   - **范围切换胶囊**：现役/前成员、全部/团体/个人曲筛选。
   - **居中吉祥物浮动徽章**：官方白兔「アイラビット」轻柔浮动（bobbing），点击喷涌爱心粒子并弹出专属萌系鼓励。
   - **Penpen 风格大按钮 CTA**：
     - 未抽状态：高亮渐变大圆角按钮，带 3D 底边、按下 Q 弹反馈与持续扫光掠影动画（`shine`），文案为「🌸 今日の推しを引く ♡」。
     - 已抽状态：柔和薄荷粉渐变状态「✨ 本日の処方は受け取り済み ♡」（`.cta.is-done`），点击平滑下滚查看今日处方签。
   - **每日状态小字**：提醒「今日の処方は、まだ受け取っていません（每日限定 1 次）」与「明日 0:00 (JST) に更新」。
3. **摇签舞台（Draw Stage）**：
   - 点击抽签后，展示粉嫩渐变玻璃签筒（`.shake-wrap.is-shaking`），内置彩色糖果/星光与摇晃木签。
   - 动画提示语「おみくじを振っています...」带跳跳点（`.draw-dots`）与「アイラビット正在摇晃签筒，请稍等一下 ♡」。
4. **处方笺结果卡片（Prescription Card）**：
   - **日期标头**：JST 日本时间标准带星期汉字，如 `2026.10.28（水）`。
   - **双栏顶部（Presc Top）**：左侧展示虚线双环矢量吉印章（大吉/中吉/小吉/吉/末吉，带今日限定徽标），右侧展示运势口号（tagline）、日文副句与彩色胶囊。
   - **微倾斜拍立得卡片（Polaroid）**：呈现成员/歌曲官方高清写真，支持轻微 hover 摆正与放大微交互。
   - **结构化处方行（Rx List）**：
     - 每日一句便签行（`.rx-item.is-phrase`）：呈现金句「签语 · motto」。
     - 幸运颜色行：带独立同心圆描边实色圆点（color-dot）与颜色名。
     - 幸运物品行：呈现萌系应援物品。
     - 今日行动行：呈现粉丝温馨行动引导。
   - **分享引导条（Share CTA）**：带光芒呼吸动效，展示「💌 今日のお守り、シェアしない？」「保存处方签 📸」，一键生成并下载/分享 9:16 高清卡片。
   - **快捷切换与导航**：下方提供「去抽今日之歌 🎵 ↗」或「查看今日之歌 🎵 ↗」、查看成员/歌曲档案按钮。
5. **特性网格与图鉴式历史记录（Feature Grid & Collection Grid）**：
   - 三栏圆角特性卡：毎日いちど、おみくじ / 運命の推しと音楽 / お守りをシェア。
   - 历史记录（`.dhist`）采用 Penpen 拍立得卡片网格，展示封面、标题、日期星期与吉彩色标签，点击历史卡片即刻回看往期签纸，带有「返回今日」按钮。
   - 本地存档备份：导出、恢复与清空功能。
