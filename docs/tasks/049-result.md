# 049 结果：抽签增加吉的级别

为抽签页（`draw.html`）与 900×1600 分享卡片增加了五级御神签吉级别（大吉、中吉、小吉、吉、末吉），让抽签与分享更具趣味与应援仪式感。

## 变更

- **五级吉词库与抽取**：
  - 在 `app.js` 定义了五级吉池 `KICHI_POOL`（全为吉，不设凶，适合偶像粉丝应援）。
  - `rollFortune` 每次抽签独立随机生成运势级别，写入 `fortune.kichi`，并连同单次抽签记录持久化至本地 `ilifefan-draw-v1`。
- **拍立得印章（圆章）升级**：
  - 拍立得上方的 `.dseal` 印章改为主显当前抽取的吉级别（字号 24px 加粗）。
  - 若为日本时间当天该模式的首抽，印章上方叠加「今日首抽」副标。
  - `.dseal` 样式增加了御神签双环印记质感（`:after` 细圆圈描边），抽推模式下自动联动该成员应援色。
- **今日运势区域**：
  - 签语栏上方的小标签展示为「签语 · <吉级别>」（如「签语 · 大吉」）。
  - 今日运势列表新增「运势」项，突出呈现当前吉级别。
- **900×1600 分享卡片**：
  - 右上方双环印章同步绘制吉级别；首抽时带有顶部弧度/副标「今日首抽」。
  - 运势列表新增「运势」行，吉级别使用高亮主色，4 行排版整体垂直微调，留白充裕且不遮挡底部官方版权声明与粉丝站标注。
- **历史记录与向下兼容**：
  - 底部最近记录卡片（`.dhi`）标记出对应抽签的吉级别（如「大吉 · 首抽」「中吉」等）。
  - `packFortune` 与历史数据读取全面兼容，旧记录或缺省字段时默认回退为「吉」，导出与导入存档平滑无报错。
